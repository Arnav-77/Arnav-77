**Projects**
- **[BERT LoRA Fine-Tuning](https://github.com/Arnav-77/REPO)** — LoRA implemented from scratch (no `peft`) on Banking77. Kept ~95% of full fine-tuning accuracy (87.9% vs 92.7%) training 1.1% of parameters, with ~38% less GPU memory. A rank sweep showed setup beat rank: warmup + early stopping took r=8 from 45% → 84%.
- **[Stateful Research Agent](https://github.com/Arnav-77/REPO)** — 5-step agent (retrieve → extract → draft → critique → revise) with a self-correcting critic loop and rule-based grounding validator. Built an HTML trace viewer (latency, tokens, critic verdicts, diffs) and used it to move the answerability check from retrieval to the grounding layer.
